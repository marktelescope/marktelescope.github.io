Privacy policy

This policy covers a google docs tool, a private tool used only by its owner.

What it accesses

With the owner's permission, the tool uses Google's APIs to read and manage files in the owner's own Google Drive, and to read the owner's Google Slides presentations.

How data is used

  • Data is used only to perform the action the owner runs, such as exporting or backing up files.
  • Nothing is sold, shared with third parties, or used for advertising.
  • OAuth tokens are stored only on systems the owner controls.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party access.
